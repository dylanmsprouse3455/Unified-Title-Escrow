Quick tutorial for new users

This page is built to walk you through an opening order one piece at a time.

1. Start here
Look at “Your Next Step” first
That box tells you the next thing you should do right now, so you do not have to guess where to begin.
2. Watch for special file flags
Check the warning box above the checklist
If the file has things like Mobile Home, POA, Mail-away, or No Title Order, the tracker lists the extra things you need to do.
3. The checklist begins below
Open each section and work top to bottom
The blue checklist area below is the actual workflow. The section with your next incomplete step opens automatically first.
4. Need more detail?
Use the ? button inside any step
That opens plain-English help showing what to do, where to do it, why it matters, and how to know you did it right.
